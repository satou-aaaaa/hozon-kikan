# 何年とっておく？（hozon-kikan）

お店・会社・病院・薬局・事業主などの帳簿や書類を読んで、何年とっておくか（2年・3年・4年・5年・7年・10年・15年）を当てる1日5問の学習ゲーム。正解したら、どの分野の書類か（お金の帳簿・決算／医療・薬／保険・許可の仕事）も選ぶ。仕事のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/hozon-kikan/>

- 中身は e-Gov 法令検索（<https://laws.e-gov.go.jp/>）の商法 第19条・会社法 第432条・第435条・医師法 第24条・歯科医師法 第23条・保健師助産師看護師法 第42条・薬剤師法 第27条・第28条・古物営業法 第18条・質屋営業法 第14条・法人税法施行規則 第59条・所得税法施行規則 第63条・雇用保険法施行規則 第143条・健康保険法施行規則 第34条・労働者災害補償保険法施行規則 第51条・建築士法施行規則 第21条・宅地建物取引業法施行規則 第18条に書いてある保存期間だけです（2026-11-18 に読みました）。
- 説明は条文を、短く言いかえたものです。年数の数え始めの細目・例外・経過措置・家庭の書類の目安は省いています。公式の情報の代わりではありません。実際に書類をとっておくときは、所管の役所の案内や専門家に確かめてください。
- 2段目は、書類の分野で分けています。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
